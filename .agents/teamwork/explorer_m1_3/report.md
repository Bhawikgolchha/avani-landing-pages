## 3. Exact File Integrity Checks & Verification Specifications

To ensure the exported artifacts are completely sound and ready for production, the Worker and verification gates must execute the following automated integrity checks.

### 3.1 HTML Integrity Specification (`mockup.html`)

1. **Doctype Declaration**:
   - The file MUST begin with a valid HTML5 doctype declaration: `<!DOCTYPE html>` or `<!doctype html>` (case-insensitive, optional leading whitespace/BOM allowed).
   - Regex: `^\s*<!DOCTYPE\s+html>` (case-insensitive).
2. **HTML Structure Completeness**:
   - MUST contain opening and closing tags: `<html`, `<head>`, `</head>`, `<body>`, `</body>`, `</html>`.
   - Character encoding tag `<meta charset="utf-8">` or `<meta charset="UTF-8">` MUST be present in `<head>`.
   - Responsive viewport tag `<meta name="viewport" ...>` MUST be present in `<head>`.
3. **Encoding & Text Cleanliness**:
   - File MUST be valid UTF-8.
   - MUST NOT contain Unicode replacement characters (`\uFFFD`), unresolved HTML escape artifacts (`&amp;amp;`), or raw unclosed markup blocks.
4. **File Size Bounds**:
   - A complete desktop landing page mockup with comprehensive content and inline/Tailwind styles is substantial.
   - **Minimum Size Threshold:** `≥ 5,000 bytes` (5 KB). Anything smaller indicates a truncated response or empty placeholder.
   - **Typical Size Range:** `25,000 bytes` to `150,000 bytes` (25 KB – 150 KB).
5. **Styling Framework Presence**:
   - MUST link to Tailwind CSS (via `<script src="https://cdn.tailwindcss.com"></script>` or inline Tailwind classes like `flex`, `grid`, `rounded-`, `text-`, `bg-`).

### 3.2 PNG Binary Integrity Specification (`mockup.png`)

1. **Exact 8-Byte Magic Number (Header Signature)**:
   - According to RFC 2083 / ISO/IEC 15948:2004, every valid PNG file MUST start with the exact 8-byte sequence:
     ```
     Hex:     89  50  4E  47  0D  0A  1A  0A
     Decimal: 137 80  78  71  13  10  26  10
     ASCII:   \x89 P   N   G   \r  \n  \x1a \n
     ```
   - Any file lacking these exact leading 8 bytes is corrupted or not a PNG.
2. **Chunk Structure Verification**:
   - **First Chunk (`IHDR`)**:
     - Offset 8–11: 4-byte chunk length = `0x00 0x00 0x00 0x0D` (13 bytes).
     - Offset 12–15: 4-byte chunk type = `0x49 0x48 0x44 0x52` (`IHDR`).
     - Offset 16–19: Width (32-bit big-endian unsigned integer). Must be `≥ 1024` for desktop screens.
     - Offset 20–23: Height (32-bit big-endian unsigned integer). Must be `≥ 1024` for full landing pages.
     - Offset 24–28: Bit depth, color type, compression method, filter method, interlace method.
   - **Last Chunk (`IEND`)**:
     - The file MUST terminate with the `IEND` chunk:
       `0x00 0x00 0x00 0x00 0x49 0x45 0x4E 0x44 0xAE 0x42 0x60 0x82`
3. **File Size Bounds**:
   - High-resolution desktop landing page screenshots (1440px wide by 2000–6000px high) are large compressed bitmaps.
   - **Minimum Size Threshold:** `≥ 20,000 bytes` (20 KB). A PNG under 20 KB for a 1440px page indicates a blank transparent canvas or truncated stream.
   - **Typical Size Range:** `300,000 bytes` to `3,500,000 bytes` (300 KB – 3.5 MB).
4. **OS / Tool Level Verification**:
   - On macOS, `file mockups/prototype_1/mockup.png` MUST report:
     `PNG image data, 1440 x ..., 8-bit/color ...`
   - `sips -g pixelWidth -g pixelHeight mockups/prototype_1/mockup.png` MUST exit with code 0 and return integer dimensions matching `metadata.json`.

### 3.3 Metadata Integrity Specification (`metadata.json`)

1. **JSON Parser Compliance**:
   - File MUST parse with standard strict JSON parsers (`json.loads` in Python, `JSON.parse` in Node/JS) with zero syntax errors.
2. **Field Validation**:
   - `projectId`, `screenId`, `screenResourceName` must be non-empty strings.
   - `dimensions.width` and `dimensions.height` must match the actual pixel dimensions extracted from the PNG IHDR header.
   - `fileSizes.htmlBytes` must match `os.path.getsize('mockups/prototype_X/mockup.html')`.
   - `fileSizes.pngBytes` must match `os.path.getsize('mockups/prototype_X/mockup.png')`.
   - `checksums.htmlSha256` and `checksums.pngSha256` must match the SHA-256 digest of the files on disk.
   - `exportedAt` must be a valid UTC ISO-8601 timestamp string (`YYYY-MM-DDTHH:MM:SSZ`).

## 4. Base64 PNG Decoding & Binary Safety Protocol for Worker

Stitch MCP's `download_file` tool returns the screenshot image as a base64 encoded string inside the JSON object `{ "image": "iVBORw0KGgo...", "image_metadata": {...} }`.

To guarantee zero corrupted bytes during decoding and file persistence, the Worker MUST follow this precise protocol.

### 4.1 Base64 Sanitization & Normalization

1. **Data URL Header Stripping**:
   Some MCP servers or APIs prepend data URL schemes (e.g. `data:image/png;base64,`).
   - The decoder MUST check if a comma `,` exists in the string:
     ```python
     if "," in b64_str:
         b64_str = b64_str.split(",", 1)[1]
     ```
2. **Whitespace & Newline Removal**:
   Base64 strings transmitted over JSON or shell pipelines may contain internal newline escapes (`\r`, `\n`) or extraneous whitespace.
   - Strip all ASCII whitespace characters:
     ```python
     import re
     b64_clean = re.sub(r"\s+", "", b64_str)
     ```
3. **Padding Correction**:
   Standard base64 encoding requires length to be a multiple of 4.
   - If length is not divisible by 4, append appropriate `=` padding:
     ```python
     missing_padding = len(b64_clean) % 4
     if missing_padding:
         b64_clean += "=" * (4 - missing_padding)
     ```

### 4.2 Atomic File Writing (Crash-Resistant)

Directly writing to `mockups/prototype_X/mockup.png` while other processes or watchers are active risks partial reads or file lock contention. The Worker MUST write to a temporary file in the same directory and execute an atomic rename:

```python
temp_path = os.path.join(output_dir, "mockup.png.tmp")
target_path = os.path.join(output_dir, "mockup.png")

# 1. Write binary bytes
with open(temp_path, "wb") as f:
    f.write(binary_bytes)
    f.flush()
    os.fsync(f.fileno())  # Ensure bytes hit disk

# 2. Atomic rename (POSIX atomic replace)
os.replace(temp_path, target_path)
```

### 4.3 Deterministic Worker Implementation Reference (Python 3)

The Worker can execute the following production-grade Python script to extract, decode, validate, and write both mockups:

```python
#!/usr/bin/env python3
"""
Stitch MCP Mockup Artifact Saver & Binary Validator
Usage: Import save_mockup_artifacts() in the Worker execution script.
"""

import os
import re
import json
import base64
import struct
import hashlib
from datetime import datetime, timezone

PNG_MAGIC = b"\x89PNG\r\n\x1a\n"

def decode_png_base64(b64_str: str) -> bytes:
    """Safely decodes base64 string to PNG bytes with sanitization."""
    if not b64_str or not isinstance(b64_str, str):
        raise ValueError("Invalid or empty base64 image data")
    
    # Strip Data URL scheme if present
    if "," in b64_str:
        b64_str = b64_str.split(",", 1)[1]
        
    # Strip whitespace/newlines
    b64_clean = re.sub(r"\s+", "", b64_str)
    
    # Correct padding
    missing_pad = len(b64_clean) % 4
    if missing_pad:
        b64_clean += "=" * (4 - missing_pad)
        
    binary_data = base64.b64decode(b64_clean)
    
    # Validate magic bytes
    if not binary_data.startswith(PNG_MAGIC):
        raise ValueError(
            f"Decoded bytes do not match PNG magic signature! "
            f"Got: {binary_data[:8]!r}, Expected: {PNG_MAGIC!r}"
        )
        
    return binary_data

def inspect_png_ihdr(png_bytes: bytes) -> tuple[int, int]:
    """Extracts width and height from PNG IHDR chunk without external dependencies."""
    if len(png_bytes) < 24:
        raise ValueError("PNG byte stream too short to contain IHDR")
    
    # IHDR chunk type is at bytes 12..16
    chunk_type = png_bytes[12:16]
    if chunk_type != b"IHDR":
        raise ValueError(f"Expected IHDR chunk at offset 12, got: {chunk_type!r}")
        
    # Width and Height are two 32-bit big-endian unsigned integers at bytes 16..24
    width, height = struct.unpack(">II", png_bytes[16:24])
    return width, height

def compute_sha256(data: bytes) -> str:
    return hashlib.sha256(data).hexdigest()

def save_mockup_artifacts(
    prototype_dir: str,
    prototype_id: str,
    title: str,
    creative_direction: str,
    screen_data: dict,
    html_raw: str,
    png_base64: str,
) -> dict:
    """
    Saves mockup.html, mockup.png, and metadata.json with atomic writes and full verification.
    """
    os.makedirs(prototype_dir, exist_ok=True)
    
    # 1. Decode & Verify PNG
    png_bytes = decode_png_base64(png_base64)
    png_width, png_height = inspect_png_ihdr(png_bytes)
    
    if len(png_bytes) < 20000:
        raise ValueError(f"PNG size ({len(png_bytes)} bytes) is below minimum threshold (20000 bytes)")
    if png_width < 1024 or png_height < 1024:
        raise ValueError(f"PNG dimensions {png_width}x{png_height} below desktop minimum (1024x1024)")
        
    # 2. Verify HTML
    if not html_raw or not html_raw.strip():
        raise ValueError("HTML content is empty")
    html_clean = html_raw.strip()
    if not re.match(r"^<!DOCTYPE\s+html>", html_clean, re.IGNORECASE):
        raise ValueError("HTML does not start with <!DOCTYPE html>")
    html_bytes = html_clean.encode("utf-8")
    if len(html_bytes) < 5000:
        raise ValueError(f"HTML size ({len(html_bytes)} bytes) is below minimum threshold (5000 bytes)")

    # 3. Write HTML atomically
    html_path = os.path.join(prototype_dir, "mockup.html")
    html_tmp = html_path + ".tmp"
    with open(html_tmp, "w", encoding="utf-8") as f:
        f.write(html_clean)
        f.flush()
        os.fsync(f.fileno())
    os.replace(html_tmp, html_path)
    
    # 4. Write PNG atomically
    png_path = os.path.join(prototype_dir, "mockup.png")
    png_tmp = png_path + ".tmp"
    with open(png_tmp, "wb") as f:
        f.write(png_bytes)
        f.flush()
        os.fsync(f.fileno())
    os.replace(png_tmp, png_path)

    # 5. Assemble and write metadata.json
    now_iso = datetime.now(timezone.utc).isoformat().replace("+00:00", "Z")
    meta_payload = {
        "prototypeId": prototype_id,
        "title": title,
        "creativeDirection": creative_direction,
        "projectId": screen_data.get("projectId") or screen_data.get("name", "").split("/")[1],
        "screenId": screen_data.get("id") or screen_data.get("name", "").split("/")[-1],
        "screenResourceName": screen_data.get("name", ""),
        "deviceType": screen_data.get("deviceType", "DESKTOP"),
        "modelId": screen_data.get("modelId", "GEMINI_3_8_FLASH"),
        "htmlFileResource": screen_data.get("htmlCode", {}).get("name", ""),
        "screenshotFileResource": screen_data.get("screenshot", {}).get("name", ""),
        "dimensions": {
            "width": png_width,
            "height": png_height
        },
        "fileSizes": {
            "htmlBytes": len(html_bytes),
            "pngBytes": len(png_bytes)
        },
        "checksums": {
            "htmlSha256": compute_sha256(html_bytes),
            "pngSha256": compute_sha256(png_bytes)
        },
        "stitchTimestamps": {
            "createTime": screen_data.get("createTime", now_iso),
            "updateTime": screen_data.get("updateTime", now_iso)
        },
        "exportedAt": now_iso
    }
    
    meta_path = os.path.join(prototype_dir, "metadata.json")
    meta_tmp = meta_path + ".tmp"
    with open(meta_tmp, "w", encoding="utf-8") as f:
        json.dump(meta_payload, f, indent=2)
        f.flush()
        os.fsync(f.fileno())
    os.replace(meta_tmp, meta_path)
    
    print(f"Successfully saved and verified {prototype_id} artifacts at {prototype_dir}")
    return meta_payload
```

            errors.append(f"{html_path}: HTML missing valid <!DOCTYPE html> preamble.")
        if "\uFFFD" in html_content:
            errors.append(f"{html_path}: HTML contains Unicode replacement characters (\\uFFFD).")
        
        # Brand string checks
        missing_brand = []
        for pat in REQUIRED_BRAND_PATTERNS:
            if not re.search(pat, html_content, re.IGNORECASE):
                missing_brand.append(pat)
        if missing_brand:
            errors.append(f"{html_path}: Missing {len(missing_brand)} required brand tokens: {missing_brand}")

    except Exception as e:
        errors.append(f"{html_path}: Failed reading HTML: {e}")

    # 3. PNG Checks
    try:
        with open(png_path, "rb") as f:
            png_bytes = f.read()
        if len(png_bytes) < 20000:
            errors.append(f"{png_path}: PNG size ({len(png_bytes)} bytes) is below minimum 20,000 bytes.")
        if not png_bytes.startswith(PNG_MAGIC):
            errors.append(f"{png_path}: Invalid PNG signature (header does not match 8-byte PNG magic).")
        if len(png_bytes) >= 24:
            if png_bytes[12:16] != b"IHDR":
                errors.append(f"{png_path}: IHDR chunk not found at offset 12.")
            else:
                width, height = struct.unpack(">II", png_bytes[16:24])
                if width < 1024 or height < 1024:
                    errors.append(f"{png_path}: Dimensions ({width}x{height}) below minimum 1024x1024.")
        if not png_bytes.endswith(b"IEND\xaeB`\x82"):
            errors.append(f"{png_path}: PNG does not terminate with standard IEND chunk.")
    except Exception as e:
        errors.append(f"{png_path}: Failed reading PNG: {e}")

    # 4. Metadata Checks
    try:
        with open(meta_path, "r", encoding="utf-8") as f:
            meta = json.load(f)
        req_keys = ["projectId", "screenId", "dimensions", "fileSizes", "checksums", "exportedAt"]
        for k in req_keys:
            if k not in meta:
                errors.append(f"{meta_path}: Missing key '{k}'.")
        
        # Checksum checks
        if "checksums" in meta:
            calc_html_sha = hashlib.sha256(html_bytes).hexdigest()
            calc_png_sha = hashlib.sha256(png_bytes).hexdigest()
            if meta["checksums"].get("htmlSha256") != calc_html_sha:
                errors.append(f"{meta_path}: htmlSha256 mismatch (recorded: {meta['checksums'].get('htmlSha256')}, calculated: {calc_html_sha}).")
            if meta["checksums"].get("pngSha256") != calc_png_sha:
                errors.append(f"{meta_path}: pngSha256 mismatch (recorded: {meta['checksums'].get('pngSha256')}, calculated: {calc_png_sha}).")
    except Exception as e:
        errors.append(f"{meta_path}: Failed reading/parsing JSON: {e}")

    return errors
