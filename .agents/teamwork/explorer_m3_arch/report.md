### 1.3 Recommended Scaffolding Strategies for Worker Agent

#### Strategy A (Recommended): Direct Configuration & Source Authoring
Because Next.js projects are defined entirely by `package.json`, `tsconfig.json`, `next.config.mjs`, `postcss.config.mjs`, `tailwind.config.ts`, `.eslintrc.json`, and the `src/app/` folder, the cleanest and fastest approach is to write the verified configuration files directly into the repository root and run `npm install`. This eliminates `create-next-app` directory checks and guarantees byte-accurate control over all versions.

If the Worker desires the initial template files generated by `create-next-app`:

### 3.2 Typography Tokens & Google Fonts Setup
Avani requires three distinct typographic voices across the landing pages:
1. **Editorial & Display (`Cinzel`)**:
   - Google Font: `Cinzel` (variable or `weights: ['400', '600', '700', '900']`).
   - CSS Variable: `--font-cinzel`.
   - Used for majestic hero titles, section headlines, and editorial quotes.
2. **Clean UI & Body (`Plus Jakarta Sans`)**:
   - Google Font: `Plus_Jakarta_Sans` (variable `weights: ['300', '400', '500', '600', '700']`).
   - CSS Variable: `--font-plus-jakarta`.
   - Used for main reading copy, card descriptions, navigation links, and buttons.
3. **High-Tech & Telemetry (`JetBrains Mono`)**:
   - Google Font: `JetBrains_Mono` (variable `weights: ['400', '500', '700']`).
   - CSS Variable: `--font-jetbrains-mono`.
   - Used for Prototype 2 HUD coordinates, telemetry counters, metrics, and climate checklist tags.

## 4. `next.config.mjs` and `tsconfig.json` Requirements

### 4.1 `next.config.mjs` Specification
In Next.js App Router, Three.js and submodules like `three-stdlib` require transpilation. We specify `transpilePackages: ['three']`:
```js
/** @type {import('next').NextConfig} */
const nextConfig = {
  transpilePackages: ['three'],
  reactStrictMode: true,
  images: {
    formats: ['image/avif', 'image/webp'],
  },
};

export default nextConfig;
```

### 4.3 WebGL SSR Isolation Best Practice
Because Node.js does not have WebGL contexts or `window`, all 3D canvas components MUST be dynamically imported with `ssr: false`:
```tsx
import dynamic from 'next/dynamic';

const P1Scene = dynamic(
  () => import('@/components/prototype1/P1Scene').then((mod) => mod.P1Scene),
  {
    ssr: false,
    loading: () => (
      <div className="fixed inset-0 bg-avani-darkforest flex items-center justify-center">
        <div className="h-10 w-10 border-2 border-avani-cyan border-t-transparent animate-spin rounded-full" />
      </div>
    ),
  }
);
```
